**Apo-Tope** (HackMIT 2026, September 2026)

- Predicts antibody binding sites (epitopes) on influenza hemagglutinin by scoring every amino acid for how likely an antibody is to touch it, using ESM-2 protein language model embeddings with XGBoost
- Combines binding predictions with a conservation score, how rarely each site mutates across ~9,600 real flu sequences, into a single "durability" score that highlights targets the virus can't easily escape

- Built an interactive 3D web app with a structure viewer, binding-site clustering, region and durability charts, and a sequence-level view; users can upload their own structure or a PDB ID for real-time scoring
